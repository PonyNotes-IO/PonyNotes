# 我的空间菜单 - 功能实现说明

## 🎯 功能概述

在"我的空间"主菜单右侧添加了一个"+"按钮，允许用户添加新的文件夹、笔记本和笔记。同时为所有子项目提供了重命名功能，以及完整的右键菜单支持。

## ✨ 实现的功能

### 1. 添加按钮
- **位置**：在"我的空间"标题右侧，展开/收起按钮（">"）的左边
- **样式**：蓝色圆形背景，白色"+"图标
- **功能**：点击后弹出添加项目对话框

### 2. 添加项目对话框
- **标题**：添加新项目
- **内容**：
  - 项目类型选择（单选按钮）
    - 📁 文件夹
    - 📚 笔记本  
    - 📝 笔记
  - 项目名称输入框
- **按钮**：
  - 取消：关闭对话框
  - 添加：创建新项目（需要输入名称）

### 3. 重命名功能
- **位置**：每个子项目右侧，在添加按钮和删除按钮之间
- **图标**：编辑图标（✏️）
- **功能**：点击后弹出重命名对话框
- **支持**：所有类型的项目都可以重命名（文件夹、笔记本、笔记）

### 4. 删除功能
- **位置**：每个子项目右侧
- **图标**：删除图标（🗑️）
- **功能**：点击后弹出确认删除对话框

### 5. 右键菜单功能 ⭐ 新增
- **触发方式**：右键点击任意项目名称
- **菜单内容**：
  - **重命名**：编辑图标，重命名项目
  - **移动到**：移动图标，仅文件夹和笔记本显示，快捷键 ⌘⌥M
  - **分享**：分享图标，快捷键 ⌘⌥S
  - **加星**：星形图标，快捷键 ⌘⇧C
  - **复制**：复制图标，快捷键 ⌘C
  - **分隔线**
  - **删除**：删除图标，红色文字

## 🔧 技术实现

### 新增方法
1. **`_showContextMenu(BuildContext context, MySpaceMenuItem item)`**
   - 显示右键菜单
   - 计算菜单位置
   - 调用 `_buildContextMenuItems` 构建菜单项

2. **`_buildContextMenuItems(MySpaceMenuItem item)`**
   - 构建右键菜单项列表
   - 根据项目类型动态显示菜单项
   - 包含图标、文字和快捷键显示

3. **`_handleContextMenuAction(String action, MySpaceMenuItem item)`**
   - 处理右键菜单选择
   - 根据选择的操作调用相应的方法

4. **`_onMoveItem(MySpaceMenuItem item)`** ⭐ 新增
   - 移动项目功能（待实现）
   - 显示提示信息

5. **`_onShareItem(MySpaceMenuItem item)`** ⭐ 新增
   - 分享项目功能（待实现）
   - 显示提示信息

6. **`_onFavoriteItem(MySpaceMenuItem item)`** ⭐ 新增
   - 加星项目功能（待实现）
   - 显示提示信息

7. **`_onCopyItem(MySpaceMenuItem item)`** ⭐ 新增
   - 复制项目功能（待实现）
   - 显示提示信息

### 新增组件
1. **`_AddRootItemDialog`**：添加项目的对话框组件
   - 类型选择器（单选按钮组）
   - 名称输入框
   - 确认和取消按钮
   - 自动聚焦到输入框

2. **`_RenameItemDialog`**：重命名项目的对话框组件
   - 显示当前名称
   - 名称输入框
   - 确认和取消按钮
   - 自动聚焦到输入框
   - 验证新名称不能为空且不能与原名称相同

## 📱 使用方法

### 添加新项目
1. **添加文件夹**：
   - 点击"我的空间"右侧的"+"按钮
   - 选择"📁 文件夹"类型
   - 输入文件夹名称
   - 点击"添加"按钮

2. **添加笔记本**：
   - 点击"+"按钮
   - 选择"📚 笔记本"类型
   - 输入笔记本名称
   - 点击"添加"按钮

3. **添加笔记**：
   - 点击"+"按钮
   - 选择"📝 笔记"类型
   - 输入笔记名称
   - 点击"添加"按钮

### 重命名项目
1. **重命名任意项目**：
   - 点击项目右侧的编辑图标（✏️）
   - 在弹出的对话框中输入新名称
   - 点击"重命名"按钮确认

### 删除项目
1. **删除任意项目**：
   - 点击项目右侧的删除图标（🗑️）
   - 在确认对话框中点击"删除"按钮

### 右键菜单操作 ⭐ 新增
1. **打开右键菜单**：
   - 右键点击任意项目名称
   - 菜单会在项目右侧弹出

2. **重命名**：
   - 选择"重命名"菜单项
   - 弹出重命名对话框

3. **移动到**：
   - 选择"移动到"菜单项（仅文件夹和笔记本）
   - 显示功能待实现提示

4. **分享**：
   - 选择"分享"菜单项
   - 显示功能待实现提示

5. **加星**：
   - 选择"加星"菜单项
   - 显示功能待实现提示

6. **复制**：
   - 选择"复制"菜单项
   - 显示功能待实现提示

7. **删除**：
   - 选择"删除"菜单项
   - 弹出确认删除对话框

## 🎨 UI设计

### 添加按钮样式
- 背景色：主题色的10%透明度
- 图标：主题色的"+"符号
- 大小：16x16像素
- 圆角：4像素
- 内边距：4像素

### 操作按钮样式
- **添加按钮**：蓝色"+"图标（仅文件夹和笔记本显示）
- **重命名按钮**：编辑图标（所有项目都显示）
- **删除按钮**：删除图标（所有项目都显示）
- 按钮大小：16x16像素
- 颜色：项目文字颜色的60%透明度

### 右键菜单样式 ⭐ 新增
- **菜单位置**：项目右侧弹出
- **菜单项样式**：图标 + 文字 + 快捷键
- **图标大小**：16x16像素
- **快捷键样式**：小字体，半透明颜色
- **删除项样式**：红色图标和文字
- **分隔线**：标准Material Design分隔线

### 对话框样式
- 标准Material Design对话框
- 类型选择器使用单选按钮
- 名称输入框使用OutlineInputBorder
- 按钮使用标准Material按钮样式

## 🔄 状态管理

- 新项目会自动添加到 `_menuItems` 列表
- 重命名操作会立即更新项目名称
- 删除操作会从列表中移除项目
- 使用 `setState` 触发UI更新
- 新项目默认状态：未展开，无子项目

## 📝 注意事项

1. **ID生成**：使用时间戳生成唯一ID，确保不会重复
2. **状态管理**：新项目默认未展开，避免界面混乱
3. **输入验证**：
   - 项目名称不能为空，否则"添加"按钮禁用
   - 重命名时新名称不能为空且不能与原名称相同
4. **类型安全**：使用枚举确保类型选择的类型安全
5. **递归操作**：重命名和删除操作支持任意层级的项目
6. **右键菜单** ⭐ 新增：
   - 菜单位置根据项目位置动态计算
   - 根据项目类型动态显示菜单项
   - 保留原有按钮功能，提供多种操作方式
